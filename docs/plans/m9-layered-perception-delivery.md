## 目标、范围与非目标

按 [DEC-121](../decisions/DEC-121-three-tier-perception-delivery.md) 建成高频 CV/
跟踪、事件驱动识别和低频任务语义闭环，降低实际识别/模型开销并保持事件和
内容任务质量。覆盖基线/账本、跟踪、识别调度、语义注意、时间证据、平台 damage、
可观测性、资源及产品默认切换。

不修改 pinned 依赖，不引入第二个 Executor、GPU 视频栈或默认 NanoTrack，不把
固定采样间隔当实得频率，不在无声音/覆盖证据时宣称完整观看。后续确认缺口按
现有反馈流程处理；本计划不隐式授权升级或直接修改 third_party。

## 阶段与交付顺序

第一阶段 25→26：先把“采样成功”和“识别证据成功”分开，通过无盲周期和未知
投影测试。第二阶段 27→28：轻量跟踪与慢识别解耦，不能在 CV 循环中同步等待
全帧 OCR。第三阶段 29→30：任务相关语义升级和时间证据；31 在平台侧推进，
不阻断无 damage 的回退。32 随各阶段补齐，33 集中收口，不预先降低默认采样
间隔或开启每帧 detector。各阶段可独立评审/回退，不能为刷资源指标吞掉事件。

## M9-28 分步验收

1. 有界派发原语（DEC-124）：Executor worker、一个在途/待消费结果加一个 latest、
   两个像素代次槽、原帧时间/序号、完成消费背压、代次/取消/超时/异常/关闭。
   先用受控 capture host/慢 observer 验证，不在此步开启产品异步识别。
2. 采样 owner 迁移：CV 双基线与 tracker 只归采样上下文所有；识别 session 保持
   单独串行，使用原帧/代次结果重建识别基线和模板。OCR 运行期间仍处理采样，
   并验证历史/未知投影、旧标注失效及显式前台优先，禁止跨线程共享 session。
3. ROI 与产品实验接线：按候选/文字变化/低置信/年龄形成有界工作，公开空间计划
   与实际证据覆盖一致。DEC-126先交付不作覆盖承诺的raw区域观察和年龄完整巡检，
   复用默认关闭的async实验；局部身份/精确覆盖、资源峰值和质量退出门禁仍开放。
   Windows、真实桌面与模型质量/CPU/5–10Hz 配对结果作为最终退出门禁。

## 验证矩阵与退出条件

| 场景 | 必须观察到的结果 |
| --- | --- |
| 静态/微动/累积慢变化 | 采样计数推进；识别/模型调用分频；累积变化相对识别基线仍可见，不能因相邻帧相似而永久忽略 |
| 媒体/字幕/首帧全屏/短暂插入 | 启发式不作语义保证；任务相关证据不被一律抑制；缺帧/漏检/观察延迟如实统计 |
| 新候选/遮挡/相似对象/重现 | 再识别路径明确；loss 不冒充消失；有效覆盖后确认；身份与语义版本不串用 |
| 来源/尺寸/策略/权限变更 | 旧基线/计划/标注失效；重新 bootstrap；迟到结果不能复活旧对象或授权 |
| 正常/后端异常/拒绝/运行中取消/超时/shutdown | 每个 future 明确终态；不提交失败基线/覆盖；停止无悬挂、无自等待 |
| 多消费者/无用户任务/前台精读 | 独立 ACK/focus，常驻源生命周期正确，前台按需刷新不被后台节流挡住 |
| 视频任务 | 定位、播放、内容理解、覆盖评估分别验证；回答动作/字幕内容问题并说明范围，音频缺失不能推断；不足与中断有明确结果 |
| 单图/多图一次请求/拼图/ROI | 相同帧集/区间，记录 token、调用数、质量、细节升级率、延迟及资源，不能仅比较图片数量 |

5/10Hz、资源和质量阈值需在 M9-33 配对运行前登记：基线、目标硬件、模型、
任务集、测试时长、样本数及统计方法。冻结负责人 Mirage 维护者，最迟在 M9
生产默认切换前完成；未冻结/未运行的项保持 Planned，不能用单测宣称性能。
