## 目标与范围

按 [DEC-111](../decisions/DEC-111-target-text-value-verification.md) 以实际目标文本值
替代普通输入步骤对全屏 OCR 的依赖；直接读取首选、受控复制可选、局部视觉回退。
固定值条件与图像观察条件分别表达，不把识别不匹配推导成派发失败，不自动重发文字。

本计划不引入浏览器扩展／CDP，不修改 pinned 依赖，不承诺全部应用暴露文本；不把
搜索输入正确扩展为提交、导航或播放成功。文档已决策不表示实现已交付。

三个工作项分别验收，复制能力不阻塞直接读取与明确的视觉回退交付。支持声明按
“平台 + 后端 + 应用／控件 + 方法”记录，不能凭单个平台或 fake 结果关闭其他范围。

## 生命周期、风险与边界

沿用 Runtime 唯一 Executor owner、既有任务 context、ActionCoordinator 和 Platform
亲和边界。文本／剪贴板 I/O 不新建线程或调度器；完成、异常、拒绝、取消、超时与
shutdown 可见。只读重验不派发复制按键，复制探测纳入事前声明的复合操作。

值正文上限 4096 UTF-8 字节，单次验证五秒且服从已有更短 deadline；一次直接读值、
至多一次获准复制、至多一次 ROI OCR。复制多格式保存上限由 M7-33 实现前冻结；
超限禁用路径，不丢格式。平台阻塞调用不声明可被强制中止。

主要风险：无障碍目标映射、同名节点／重建、IME 预编辑、剪贴板来源与恢复竞态。
按 DEC-111 的前提禁用不可靠路径，不用扩大模糊匹配阈值补偿。既有依赖如出现公开
能力缺口按反馈台账流程登记；平台适配缺失不登记成 Mira／Mirador 缺口。

- [ ] M7-32：实际值正确／错误与 OCR 正确／错读交叉矩阵；同名双框、建议词、占位符、

- [ ] 全路径：正常完成、任务异常、提交拒绝、运行中取消、超时、接管和 shutdown；
  资源上限与脱敏；ASAN/UBSAN，跨上下文／恢复竞态增加 TSAN 或故障注入。

  无无障碍／自绘场景的局部视觉路线；每种不可用后端的明确诊断。

- [ ] 契约、实现、测试、工具说明、安全文档与逐平台证据同步后再启用新默认选路。
