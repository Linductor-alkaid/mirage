# DEC-127：按处理层限制图像分辨率

> 状态：Accepted
> 日期：2026-10-28
> 负责人：Mirage 维护者
> 冻结里程碑：M9
> 替代/被替代：无；补充 DEC-125/126

## 背景与决策

维护者要求进入算法前降分辨率，在识别精度允许范围内减少像素。当前异步路径把最长边
1600的识别图同时用于CV签名和跟踪；64²最终签名不代表此前没有处理大图。

M9-25/27/28的DEC-125异步三层路径采用独立工作图：采集图只作来源，识别图最长边
1600；CV/跟踪输入最长边320，等比缩小、不放大，再转Gray8。
小于上限的图保留尺寸，避免为满足缩小比例而破坏
已很小的目标。缩放及转换只用Mirador公开API，同步有界执行，不新增调度设施。
320是实验参数，需用坐标、目标变化、真实OCR/检测配对验证；不能宣称普遍无损。
尺寸优先取`step=ceil(max(w,h)/320)`，宽高分别除step取整（最少1），避免为填满
上限而增加非整数重采样工作；例如1024×512取256×128，1001×503取250×125。
不足320的来源不放大。算法仍使用公开area核，不自研逐点采样。

CV签名、跟踪模板、几何候选统一使用工作图坐标。变化区域和跟踪输出保守取整映射回
识别图；识别框映射到工作图后才建立模板，过小（任一边不足8像素）的模板不作可靠跟踪。
原图尺寸变化必须撤销基线，即使缩放后的尺寸相同。区域签名也先降采样再计算。
路由容差及ROI裁剪context按每轴4个CV像素回映，至少8个识别图像素；并集/歧义
和面积预算继续生效。固定8像素无法覆盖1600×900下的块边界量化，并可能切断文字。
低分辨率CV无变化不等于像素相等或语义复用；保留完整识别年龄巡检与显式精读。

OCR与YOLO继续独立从识别图或其ROI取输入，不能放大CV工作图。当前资源使用
PP-OCR检测侧960、文字行48×至多640和YOLO640的模型预处理。缩小这些模型参数
必须独立验证小字、文字框、图标召回；不得仅因置信分高或空结果而继续降低。
先保留已验证模型参数，记录不同输入分辨率的质量对照后再冻结更小参数。

## 备选与后果

全链路统一320会抹掉小字；只缩最终签名仍重复扫描大图；逐帧让LLM选择分辨率增加
成本。分层工作图增加一个至多320²×4彩色暂存和320²灰度缓冲，但不常驻原像素。
源到识别图的首次area缩放仍需访问采集像素，不能据此宣称整个采集步骤与原图大小无关。
未来按目标尺寸选择更小工作图需保持尺寸代次与重验，不纳入本次自动调参。
