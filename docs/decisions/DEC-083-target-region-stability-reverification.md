# DEC-083：目标矩形主体稳定重验（守卫区域化）

> 状态：Accepted
> 日期：2026-10-12
> 负责人：Mirage 维护者
> 工作项：M7-16，修订 DEC-072/077 的逐像素重验承诺

## 背景与问题

DEC-072/077 规定输入动作前对目标矩形做逐像素重验（零容差字节比较）。真实会话
（DeepSeek 验收，2026-10-12）中该守卫过敏感：Wayland 共享输入在 Dock 图标上被
`target_pixels_changed` 拒绝——应用启动动画与通知滑入都命中字节差异，模型被迫
"重截屏→重判定"往返，且慢模型叠加 5 秒供图年龄后几乎必然被拒。
`scoped-visual-marks-20261010.md` 已自认"严格原图像素相同会拒绝慢模型和动画页面"。

守卫的安全目的是**防止对已变化的目标施加输入**，不是检测任意像素变化。光标类
噪声本就不进采集帧；进入帧的主体稳定动画（插入符闪烁、启动脉冲、加载转圈）不改变
点击落点的语义。

## 决策

共享输入（`desktop.session.*`）与 X11 编号指针动作（`desktop.vision.click/drag/scroll`）
的派发前重验改为**分层目标稳定判定**（`desktop_stability_guard.hpp`，mirador
`detect_change` + `patch_fingerprint`，确定性、有界预算）：

1. **边距环忽略**：目标矩形外扩 8px 的环形区域内任何变化不拦截（通知从边缘滑入、
   邻接动画）。
2. **主体相似放行**：核心区（原矩形）存在变化时，比较新旧帧核心区的 32×32 灰度
   指纹，平均绝对亮度差相似度 ≥ 0.98 判为主体未变，放行。全图标替换、控件位移
   远低于该界限，仍然拒绝。
3. **不确定即拒（兜底）**：`kGlobal` 全局变化、检测器错误、指纹不可测、区域越界
   裁剪后为空——一律按原语义拒绝（`target_pixels_changed` / `stale_observation`）。
4. **不做追踪续期**：矩形内"主体移动"（拖拽中的目标）按变化拒绝，与 DEC-072
   "不追踪移动目标"一致；NanoTrack 跟踪 SPI 留作后续项，本轮不接。
5. 阈值与边距为命名常量（8px / 32px / 0.98），不做配置面；测试钉住其行为。

`desktop.vision.click_region` 保持逐像素比较：它是声明"目标区域字节级未变"语义的
保守参照实现，模型需要强保证时使用它。

## 影响

- 正常动画页面、系统通知、慢模型场景下的输入往返显著减少；拒绝语义与安全下限
  （不确定即拒、无副作用拒绝）不变。
- DEC-072/077 中"逐像素重验"表述由本决策部分修订；`post-action-verification`
  的动作后核验语义不变。
- 测试：负例（全局变化、核心区替换、检测器异常、越界区域）全部拒绝；正例（边缘
  环动画、插入符闪烁级噪声）放行；现有拒绝恢复路径不受影响。
