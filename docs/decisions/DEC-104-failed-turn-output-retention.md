# DEC-104：失败轮次保留模型正文

> 状态：Accepted
> 日期：2026-10-18
> 负责人：Mirage 维护者
> 冻结里程碑：M6-46

## 问题与决策

维护者的真实 Wayland 会话在桌宠排除前置检查处失败。即使模型生成最终说明，动作核验
把轮次判失败后，ModelLayer 也不再保留最终答案；UI 又将流式正文直接替换为错误。
任务是否成功和模型说了什么必须分别展示。失败/取消状态不因此变成成功，不放宽桌面守卫。

复用 pinned ConversationLoopResult.answer 与 Mirage 既有 conversation::Part；不修改
依赖，不新增调度设施。模型已产生的最终答案，即使宿主后置核验失败仍保留为正文。
失败轮次经现有 text Part（保留 id terminal.reply）持久化/事件/历史传输；wire 字段、
版本及 failed/error 约束保持兼容。仍遵守 96 parts、16KiB 单项/正文分类和 64KiB 总预算，
UTF-8 截断显式标记，正文空间优先保留最终答复，旧中间文本按预算缩减。

UI 的模型正文与 failure detail 分别保存、布局与复制：报错单列在正文之后，不覆盖
正文。取消/传输失败时已收到的流式片段在当前 UI 保留；没有规范最终回复时不把预览
冒充规范历史。迟到预览不能修改终态，重连以服务端持久化 Part 为事实源。旧失败会话
已经被丢弃的最终回复不能从思考内容重建，不修改用户原始记录。

## 验证与限制

验证核验失败后的规范正文保留、IPC/持久化往返、重连、仅错误/部分输出/成功三种
显示、复制/引用与高度缓存、迟到事件及文本/parts 预算。记录实际执行的构建和消毒器。
真实 Wayland 的 pet 排除仍属 M8-06 未交付平台门禁；本决策不为其放宽 X11 检查。
