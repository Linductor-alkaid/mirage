# DEC-113：自主动作恢复与当前状态结算

> 状态：Accepted
> 日期：2026-10-22
> 更新日期：2026-10-23（跨日验证）
> 负责人：Mirage 维护者
> 部分替代：DEC-056/081/086/095/110 中执行不确定默认人工复核及永久全局围栏的规则
> 工作项：M9-20；关联 M9-09/11/12、M7-25/26、M10-07

## 背景与问题

维护者明确要求长期自主 Agent 自行处理普通执行故障。最近会话中的 input_lag 已确认
释放输入，却使 Portal 永久只读、open_uri 等独立路径被拒、历史失败永久否决任务。
2026-10-22 补齐 exec/write/edit 门禁只解决了一致性，没有解决围栏范围和恢复前提。

## 决策

1. 执行事实、恢复进度、固定条件和任务目标分开。执行 uncertain 永久如实保留；
   新观察不能证明旧输入发生，但能建立继续规划所需的当前状态。
2. 宿主记录恢复阶段：observation_required → reobserved → replanned。相同授权下、
   输入已释放后的新桌面观察建立恢复基线；新的独立操作表示从当前状态重新规划。
   恢复后的历史失败可以归档和结算，但不改成 verified。依赖 depends_on 仍只认固定
   条件的真实匹配。明确的当前条件可以只读重验，不要求证明旧输入的因果关系。
3. 在取得新观察前阻止依赖旧桌面状态的输入和通用 exec/write/edit；桌面修改工具的拒绝带本轮宿主
   action_id，不形成无法对账的未知失败。ApplicationProvider 的 launch/open_uri
   使用自身新应用观察和授权，不依赖旧点击位置；在释放确认、授权有效且故障来源
   为非应用动作时可独立派发。它不会清除旧失败或证明页面加载/播放成功。
4. input_lag 且输入已释放时保留当前授权流，等待严格更新的同源帧后重新开放输入。
   后端和 Adapter 共用同一有限状态策略，不重放失败动作、不修改原 250 ms 时序阈值。
   连续第三次 lag 停用该输入路径；成功完整输入重置连续失败计数。观察和独立能力
   仍可用。计数属于故障 episode，不是长期任务累计上限。
5. 新的独立操作可替代已重新观察的失败局部步骤；原条件及执行失败仍保留，不能通过
   depends_on 使用未匹配条件。正常执行但未满足的显式条件仍保持现有重验要求。
   任务结束使用最后相关操作之后的当前观察，回答必须说明实际目标结果及剩余未知；
   fresh_frame、进程存在和恢复状态均不证明任意用户目标。若当前观察已足够判断目标
   达成或只能给出局部结果，允许模型直接作答，无需为消除旧失败再制造一次操作。
   此时宿主接纳的是当前证据下的终态判断，旧执行及旧条件不改成 verified。
6. 取消、用户接管、权限撤回继续生效，不自动恢复授权。释放无法确认、传输关闭或
   源失效时停用受影响路径并报告具体原因，Agent 可以选择其他有效能力；没有公开
   可靠释放/重建能力时不得伪造恢复完成。这些状态不再笼统提示“人工检查”。
7. 不创建后台调度、重试线程或新的任务状态机；使用 pinned Mira Continuous 循环、
   既有工具反馈/恢复供给及 M9 观察，有限同步状态由现有序列化 owner 持有。

## 备选方案

- 仅放行 open_uri：保留 Portal 永久只读和任务历史失败死锁，不能满足自主恢复。
- 删除所有守卫：会复用旧引用、越过撤权或在输入未释放时继续，不采用。
- 新帧直接把失败改为成功：混淆当前事实与旧动作执行，不采用。

## 影响与风险

动作策略 policy_version 升至 3；普通修改工具 major=4，原自然输入 major=4 的
工具升为 5，verify 为 3。旧 proposal 按 registry 版本拒绝，持久历史不重写。恢复状态是加法证据字段，UI 仍显示原失败。
恢复并不承诺本机 input_lag 根因已消除，也不关闭真实模型/Wayland 长任务验收。

## 验证方式

机器子集为[策略 v3 夹具](../../tests/integration/data/desktop_action_policy_v3.json)；
v2 文件保留历史契约。

覆盖正常完成、无观察拒绝、观察后独立恢复、应用直接路径、未释放/撤权/取消、旧 scope
拒绝、相同/更新源帧、连续 lag 退避、恢复后再失败、归档及规范历史校验。运行 Debug、
ASAN/UBSAN/TSAN 聚焦回归并更新 native-release；实机任务验收单列。
