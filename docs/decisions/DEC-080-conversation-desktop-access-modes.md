# DEC-080：会话的三种桌面访问模式

> 状态：Accepted
> 日期：2026-10-12
> 负责人：Mirage 维护者
> 工作项：M6-38，承接 DEC-078

维护者明确要求输入框权限按钮使用「对话模式、视觉模式、完全访问」，权限随模式选择。
对话模式不注册桌面工具，不供应屏幕图片，走既有纯对话路径；视觉模式注册桌面观察、
OCR 与截图，拒绝键鼠及其他修改；完全访问允许已有修改工具，仍受服务策略、引用守卫
和系统授权限制。模式在轮次接纳时冻结；运行/提交期间禁止切换，用户先停止再调整。

沿现有 wire 值保留 default=完全访问、read_only=视觉模式，新增 chat_only=对话模式。
保留已有默认选择，避免无提示改动用户偏好；本轮不新增第四种模式。记住授权与会话
模式分别保存：选择对话/视觉不删除钥匙环令牌，但禁止相应能力。完全访问选择后，
支持且尚未记住授权时调用既有管理流程；视觉模式首次实际读屏由系统请求共享，只读
入口不会额外申请键鼠。会话菜单仅有三个模式选项，选择后收起，不包含桌面授权设置；
授权管理保留在设置页，对话模式不触发授权。

状态查询不产生系统弹窗。明确显示所选能力范围与实际系统状态，未授权不显示已具备
输入权限。旧客户端和持久偏好继续识别原 wire 值，旧服务对新增模式显式拒绝而不降级。

验证必须覆盖 IPC 新值、服务纯对话工具/图片为空、视觉只读和全访问工具集合差异、
三个菜单选项、等待和活动期间门禁、选择不丢草稿，以及小窗口明暗渲染。平台真实授权
与恢复门禁仍归 M7-10，未执行不关闭。无依赖 pin、线程、队列或新异步生命周期。

备选是仅改菜单文案、仍统一走 Agent，或每次切换模式删除系统令牌。前者不能兑现对话
模式无桌面能力，后者会重复打断用户授权。本决策分别限制每轮能力与系统恢复信息，
代价是必须展示实际授权状态并锁定进行中的模式。保留旧默认值是兼容选择；损坏或
未知的明确访问值使用对话模式，不按完整权限猜测。

完全访问选择联动保留，失败可在现有会话提示处显示。此次只收窄会话菜单呈现。
