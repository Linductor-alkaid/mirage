## 原因与路由

私有 GTK3 TreeView 原生重排产生跟随指针的 override-redirect 图标。服务端查询
确认图标的 ShapeInput 是完整矩形；不能用透明形状跳过它。取消归属检查时，
原生模型顺序改变，说明当前障碍在 Mirage 的 X11 适配边界。Mira/Mirador 不
承载 X11 窗口资源归属，故不登记依赖缺口，不修改 pinned 代码。

## 选择

仅在本动作已按下左键、严格指针祖先检查被辅助图层阻挡时，允许以下有界解析：

1. 按下前记录根窗口下已可见窗口（最多 128 个根子窗口）；通过系统 libXRes
   公开 XResQueryClients 获取目标连接的资源 base/mask（最多 256 个连接）。
   服务端资源命名空间用于确认同一连接，不读取 PID、标题或可伪造的归属属性。
2. 每次按层叠从上到下检查指针位置；最多跳过一个本次新出现的、同目标 X11
   连接创建的 InputOutput override-redirect 根子窗口。按下前已可见的窗口、
   其他连接窗口、普通顶层窗口与 InputOnly 窗口均不能成为该例外。
3. 跳过后第一个命中的根分支必须沿 XQueryTree 层叠几何命中到达原目标。
   重父窗口被图标遮住时，QueryPointer 不返回其下方 child，故不能依赖该
   逻辑指针祖先；额外最多 128 个后代/32 层，首个命中不得跳过。矩形边界
   保守处理非矩形窗口，不声称完整 ShapeInput 命中。
   外来遮挡位于图标上方或下方均拒绝。此规则确认资源归属及下方目标，不声称
   查询了 pointer grab 的实际接收者，也不保证 XDND 业务成功。
4. 服务端/编译环境无 XRes、查询失败、预算超限、目标销毁或任何不明确归属，
   回退原严格拒绝。系统 libXRes 为可选私有平台库；不自动下载、安装或导出
   到公共 API。构建开关允许明确关闭该解析。

目标焦点、几何、权限、引用年龄、动作租约、16 段/8 ms/1000 ms 预算与零延迟
释放契约不变。查询和注入仍不是原子事务，X11 同连接被作为应用信任边界；
不承诺隔离同连接内的恶意窗口或抵御其他 X11 客户端任意修改/注入。没有新
线程、队列、调度器；工作仍在原 Executor 有限调用任务内完成。

## 验收

补原生 TreeView 顺序改变和新观察后条件正例、禁止重排的不变负例、已开始
原生拖放后的取消/焦点丢失、不同连接在图标上方及下方遮挡、同连接既有图层
和辅助窗口预算负例。每次都检查左键释放、owner 收敛与旧引用拒绝。编译关闭
与运行期 XRes 缺失必须保留安全拒绝，不使用 skip 冒充兼容。Debug/Release、
ASAN/UBSAN 和 TSAN 留证，历史第二增量失败记录保留。

协议依据：[X.Org Resource Extension](https://www.x.org/releases/current/doc/resourceproto/resproto.txt)。

## 人工宿主取证方法

第四增量使用外部 GTK 测试进程与 Python 验收编排等待专用区域的主键松开。
编排启动有限 C++ driver 时显式传递自身窗口 ID 与继承的有界状态管道；driver
重新读实际状态并确认前台恰为该窗口，不强行激活宿主窗口，不把启动成功当
取焦成功。GTK 的原生事件循环只承担外部测试应用职责，没有 Mirage 业务
任务在其回调线程执行；产品动作继续进入现有 Executor finite future。
GDK 控件分配坐标按窗口 scale_factor 转成物理像素，整数 2× 另做私有回归，
不推广为任意 DPI/跨屏保证。原生状态与新观察验证分别留证，宿主失败即停止。

外部编排可在松键后等待 0.5 秒再启动首次观察，属于测试应用绘制准备，不是
产品重试或延长期限，仍不能保证宿主像素稳定。宿主取消另在首段运动达到
8 个逻辑像素后请求，独立检查实际 drag-begin；私有原 50 像素故障注入保留。
四类宿主证据、较晚取消/观察拒绝失败与剩余门禁见
[2026-10-11 验收](../compatibility/user-host-gtk-pointer-20261011.md)。

第五增量诊断限于测试边界：最多四个指针/根分支分类快照，256 个连接、128 个
根子窗口预算，第五次只报告截断；不写无关窗口身份/标题/PID/像素，不作为
产品授权或归属事实源。额外查询改变时序，单次较晚取消通过不能宣布原间歇
拒绝修复。已知 GTK 文字颜色变化负例独立校验像素拒绝/范围诊断，整数 2×
管道交接与实际 50 像素宿主取消另验，见
[拒绝诊断补证](../compatibility/x11-pointer-diagnostics-20261011.md)。
