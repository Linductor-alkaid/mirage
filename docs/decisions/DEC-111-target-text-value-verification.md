# DEC-111：跨平台目标文本值验证与分层取证

> 状态：Accepted（平台无关读值契约开始实现；平台与工具接线尚未交付）
> 日期：2026-10-20
> 负责人：Mirage 维护者
> 冻结里程碑：M7
> 工作项：M7-32～34
> 替代/被替代：无；扩展 DEC-056/059/077，与 DEC-109/110 协同
> 更新日期：2026-10-20（按 DEC-056 分层修订明确精确取证为按需能力，不是普通输入默认门禁）

## 背景与问题

维护者实测 B 站任务中，`deepseek` 已正确输入。保存的会话叙述记载 OCR 将其读成
`de e p e s e k`，固定文字条件未匹配，后续回车、点击及 URI 动作均被最近动作的
`unverified` 门禁拒绝。后段工具正文已被展示预算省略，该 OCR 字符串属于会话叙述，
不是本决策独立保存的原始 OCR 输出；正确输入由维护者确认。本例说明 OCR 未匹配
不能单独证明文字输入失败。

当前 `DesktopImageTurn::observe_shared()` 在整张共享帧的 OCR 结果中寻找
`region.text == expected` 且置信度不低于 0.8 的文本。它检查文字存在，未绑定输入框
的实际值：既可能漏识别，也可能命中推荐词或页面其他位置。`action.verify` 重验固定
条件，无法用同一个易错读数解决这种阻塞。

Mirage 已有平台无关的 AccessibilityProvider、ElementReference、ClipboardProvider
和输入 owner。AccessibilityProvider 支持 `set_text`，尚无文本读取接口；SemanticNode
只有名称、描述、角色和焦点等字段，不能把名称当作输入值。Linux 剪贴板 Provider 当前
只从 X11 接线，不能假设原生 Wayland 已支持复制验证。

没有一种无条件可用于全部应用的文本读取 API。本决策选择统一的目标和值契约，通过
平台能力选择证据来源，而不以跨平台承诺掩盖自绘控件、远程桌面或权限限制。

## 决策

### 1. 需要精确取证时直接读取目标控件，受控复制备用，局部视觉兜底

维护者接受 [DEC-056 的分层验证策略](DEC-056-post-action-verification.md)：普通
文字输入完成并释放后可直接回报执行结果，不默认要求 `verify_kind`、读值或 OCR。
本决策的“默认首选”仅指已选择文本取证时的证据选路，不为每次输入自动建立精确值
条件。状态依赖、动作组结果或任务目标确需精确文本时再按本决策取证，未请求不等于
值已验证；取证实现及工具版本仍待 M7-32～34 交付。

| 路径 | 采用方式 | 能证明的事实与限制 |
| --- | --- | --- |
| 系统无障碍文本读取 | 默认首选；Linux AT-SPI Text，Windows UIA Value/Text | 已绑定控件在读取时的实际文字；无需 OCR 或改变选区，支持情况由应用与后端共同决定 |
| 受控全选复制 | 可选能力，默认关闭；仅在目标、复制来源和恢复条件均可证明时使用 | 来自该控件的新复制文本；不是任意一次剪贴板读取，不能静默修改用户剪贴板 |
| 目标 ROI 图像/OCR | 通用视觉回退，复用 Mirador | 目标区域的视觉文字证据或界面进展；不冒充确定性的实际文本值 |

不把浏览器扩展、DOM/CDP 或 WebDriver 设为桌面输入验证的前置依赖；它们可用于将来的
应用专用 Adapter，但不是本次交付范围。也不自绘字体模板去比对像素，避免依赖字体、
DPI、抗锯齿、光标闪烁和输入框滚动。

### 2. 值条件与观察条件分别声明，动作前确定

新增平台中立的 `text_value_equals` 后条件，语义为“已绑定目标的完整、已提交文本等于
预期值”。动作前固定目标身份、预期值、比较规则及允许的取证方法。直接读取与获准的
复制探测可以验证同一个值条件；不能在失败后改成“页面某处存在该词”或“取得新帧”。
已取得可靠实际值且不相等时返回 `mismatched`，不得再找较弱的 OCR 结果覆盖它。

普通输入可不声明值条件，在动作组末或依赖处观察输入框及提交后的页面，无需为获得
继续资格而声明新帧条件。明确选择视觉条件时保留其观察语义；这两条路径均保留
“文字值未确定验证”的事实；取得新帧或模型
认为输入正确，不得投影为 `text_value_equals` 成功。要求精确输入的任务若没有足够
证据，明确未验证，不能自动重发文字。

既有 `shared_text_exists`、`visual_text_exists`、`display_text_exists` 保持各自的
OCR 存在条件语义；旧未验证动作不自动迁移，不重写历史。新默认选路随 M7-34 实现
和平台验收启用，本决策本身不解除当前会话围栏。

### 3. 目标绑定与完整文本语义

默认只按需读取本次输入目标，不扫描整棵树收集所有文本。Platform Backend 内部把
临时 ElementReference 或经过验证的焦点目标绑定到实际控件，保留应用实例、窗口／
授权来源、控件 incarnation、任务及环境代数。每次读取前后复核身份与输入焦点；
控件替换、失焦、页面切换、用户接管或身份不明时失效，不能按同名控件猜测恢复。
纯图像坐标只有通过 backend 命中并建立身份后才能进入确定性读值路径；图像绑定不
自动产生语义身份，也不因 AT-SPI 可用便假设 Wayland 的窗口与坐标映射成立。

值证据必须来自本次输入派发结束后的新读取，记录单调采集区间、目标身份、方法与
内容摘要；输入前基线、旧树缓存和发送载荷都不能代替动作后的读取。只读重验取得
新的采集区间，目标或授权换代后不复用旧证明。跨组件复核沿用 Mira 的观察时间与
质量契约，不把读取完成时间伪装成更早缓存内容的采集时间。

完整替换输入比较整个值。插入输入根据输入前文本与选区计算预期结果；无法取得可靠
基线时，必须另行声明明确的完整目标值，不能只判断文本包含刚发送的字符。仅比较
已提交文本，IME 预编辑、候选文字和剪贴板原始输入载荷不能当作应用接受后的内容。
密码／受保护控件不读值、不复制；走既有受保护操作及独立结果验证。

默认按有效 UTF-8 的精确内容比较，保留大小写、空白与字符顺序。平台编码和换行表示
转换须在版本化契约中显式定义；不默认删空格、忽略大小写或使用编辑距离放行。
UIA Text 范围必须限制到绑定编辑控件，不能读取整个文档后找子串。若平台无法提供
所需完整内容或字符范围映射，返回能力不可用，不截断后宣称相等。

### 4. 复制探测是有副作用的完整操作，不能藏进只读重验

没有可跨应用直接读取任意文字的“系统光标接口”。选区是控件状态，`Ctrl+A/C` 是
实际输入。复制备用必须在原动作派发前选定，并纳入同一可取消的复合操作；验证中的
选中、复制与恢复沿既有输入 owner/单写者约束执行，不能绕过条件依赖或执行/释放围栏另发按键。
`desktop.action.verify` 继续只读，只能重新读取支持的实际值，不隐式发送复制命令。
仅支持复制探测的目标需要再次探测时，明确报告只读重验能力不足。

复制路径须同时具备以下条件，任一缺失便不启用：

- 明确的可编辑目标与稳定焦点；后端已验证该控件的全选／复制语义，不把页面全选、
  菜单快捷键或终端的中断键误当复制。自绘输入框不因能够选字便自动满足该条件。
- 能将新剪贴板所有权／版本变化归因到本次复制，并复核目标身份；仅等待几毫秒、
  读取到相同字符串或预先向剪贴板写入期望值均不构成证据。无法排除其他程序写入则
  返回 `verification_unavailable`，不得误用旧数据。
- 能在有界资源内保存并恢复受影响的原剪贴板全部格式及原选区／光标。当前纯文本
  ClipboardProvider 不满足多格式恢复要求，不得宣称无损；无法保证恢复时禁用探测。
  恢复前检查版本仍属于探测，用户或其他程序已经更新时停止恢复，避免覆盖新内容。
- 当前权限允许输入和剪贴板访问；原生 Wayland 通过受支持且已授权的会话接口访问，
  不借 XWayland 剪贴板假定可读取原生目标。复制失败不转为自动粘贴或重复输入。

恢复失败、接管或复制来源不明分别记录，不宣称复合操作无副作用。输入释放失败或
无法安全收敛继续沿既有围栏处理。复制是可选增强，不是无障碍不可用时的强制步骤。

### 5. 区分证据结果与输入执行结果

| 取证结果 | 处理 |
| --- | --- |
| `matched` | 对目标与完整值的固定条件验证通过；只证明文字值，不证明搜索提交、导航或播放 |
| `mismatched` | 已读取可靠实际值但不相等；保留差异类别，不自动重发输入 |
| `verification_unavailable` | 不支持读取、身份不明、预算不足或读取超时；不能标为文字错误 |
| `visual_condition_not_matched` | 局部 OCR 条件未命中；保留视觉证据不足，不推导键盘派发失败 |

上述为后续契约的验证结果分类，不是已交付 wire 状态。原动作的 dispatched、
input_released 与 uncertain 单独保留；uncertain 表示执行副作用未知，不能从 OCR
失败推导，也不能被新帧直接清除。具体字段和兼容版本由 M7-32 同步冻结。

固定值条件未通过时，仍阻止依赖它的新修改动作；允许对同一条件重新只读取证，以及
不依赖该条件且通过输入守卫的恢复动作。普通业务证据不足不形成全局修改围栏；
恢复操作不能擅自删除或降低原条件，执行/释放 uncertain 围栏继续保留。
如果动作前允许的另一确定性来源得到可靠匹配，可以恢复该条件及门禁；不能事后
弱化条件。需视觉取证时在相应操作前选择视觉路径，避免把普通文字输入无意绑到全屏 OCR。
确切业务成功仍须由页面或应用的结果证据独立证明。

### 6. 预算、分层与依赖复用

跨平台公开接口只表达目标、文本、选区、来源、可用性及错误，不暴露 AT-SPI、UIA、
Portal 或剪贴板原生类型。控件读取归 AccessibilityProvider；复制事务归现有输入与
ClipboardProvider 的 Platform Adapter；验证策略归 integration。Mira 保持运行／
会话与工具循环 owner，Mirador 提供 ROI、OCR 与坐标变换，不在 Mirage 复制识别算法。

首版完整期望值与读取正文各最多 4096 UTF-8 字节；超限明确失败，不能截断比较。
每次验证最多一次直接读值；一次获准复合操作最多一次复制；视觉兜底最多一次 ROI
OCR，同像素失败不重复分析。每阶段受操作已有 deadline 和取消约束，整个验证上限
五秒；用户发起的只读重验另有一次有界预算，不在后台无限轮询。剪贴板多格式保存
需要独立字节／格式数上限，在 M7-33 实现前冻结；超限禁用复制，不能丢格式。

没有新增全局 owner、私有线程、队列或调度器。有限工作沿既有 Executor 提交并消费
future；平台亲和调用留在 backend 既有受管边界，协作取消和超时不承诺强杀系统调用。
跨阶段的完成、异常、拒绝、取消、背压和 shutdown 必须在既有生命周期中可见。
取证结束即释放临时正文；普通日志、工具过程和历史只留方法、身份、摘要及结果，
不新增输入值或用户原剪贴板正文的持久副本。原任务已授权的输入载荷规则不变。

已核对 pinned Mira 的环境／观察契约、kairo 集成指南与 Mirador `OcrRequest` 的
ROI/期限接口；目标输入框读取与剪贴板事务属于 Mirage 平台适配职责。本次不新增
依赖缺口反馈，不修改任何 pinned 代码；后续若确认真实公开 API 缺口另按台账流程处理。

## 备选方案

- **全选复制作为统一默认**：通常无识别误差，但改变用户状态，跨 Wayland、终端和
  自绘控件的行为不统一；当前 Provider 缺少多格式恢复与来源证明，故仅选为受控备用。
- **仅用系统无障碍读取**：准确且轻量，故作为首选；应用可能不暴露内容，需要保留
  无确定性读取时的视觉路线，不能宣称全应用覆盖。
- **全屏／局部 OCR 加模糊匹配**：ROI 可减少计算和无关命中，仍有漏字和错序；编辑距离
  会把实际输错放行，不用作精确值条件。ROI OCR 保留为视觉证据。
- **仅凭按键发送成功、粘贴源或图像变化**：不能证明接收端已提交正确文本，不采用。
- **所有 OCR 未命中立即解除门禁**：事后降低固定条件会掩盖真实错误，不采用。

## 影响与风险

确定性读值路径避免图像识别计算，预期减少误识别与往返；这是选型依据，不是已测得
的延迟或准确率保证。主要风险是控件身份映射、应用文本暴露质量、IME 提交时机与
剪贴板恢复竞态。按目标能力声明和结果分级处理，不能以平台名称或系统 API 存在替代
应用实测。最初决策只交付设计与计划同步；随后 M7-32 平台无关契约进度见文末，
真实平台和模型工具行为仍待接线。

## 验证方式

M7-32～34 分别验证契约／直接读取、受控复制、实际模型与视觉回退。至少包含：

- 普通输入未请求值条件时不触发强制读值/OCR 或全局 unverified 围栏；显式条件只
  约束依赖步骤，恢复后仍须对原条件取证，不把可继续操作投影为值已匹配。
- `deepseek` 实际值正确而 OCR 错读时，确定性读值通过；实际值为 `deepseke` 或页面
  其他位置有 `deepseek` 时不通过。同名双输入框、占位符、建议词不构成值证据。
- 完整替换、插入／覆盖选区、空值、UTF-8、中英文 IME 未提交、长文本超限、受保护
  控件、节点重建、失焦和读取前后目标切换。读取不支持与真实不等必须可区分。
- 复制旧剪贴板假阳性、异应用写入、复制无更新、焦点丢失、多格式超限、恢复冲突／
  失败；未选定复制路径、权限不足或只读 action.verify 时不得发送探测按键。
- 阶段取消、超时、任务异常、提交拒绝、接管及 shutdown，有限资源及输入释放；
  既有固定条件、未知副作用围栏及隐私回执负例回归。
- Linux X11、原生 Wayland 和 Windows 分别验证普通控件与浏览器输入；无无障碍／
  自绘场景验证视觉路线。分开统计读值、复制、采集、OCR 和模型调用成本、误接受／
  误拒绝与端到端结果，不以 fixture 声明 B 站业务完成。

实际平台与性能验证均未运行：本次范围为文档。负责人 Mirage 维护者；补跑条件为
关联工作项实现、目标平台及授权环境就绪。未验证项保持 Planned，不声明跨平台已交付。

## M7-32 首个实施边界（2026-10-20）

新增同步 `AccessibilityProvider::read_text_value` SPI，默认显式不支持。请求仅接受
带 scope 的确切 reference；不允许语义名称、坐标或提示回退。结果必须回传同一
scope/ref、本次调用内的单调采集区间、完整且已提交的有效 UTF-8 正文及来源。
