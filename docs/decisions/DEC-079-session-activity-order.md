# DEC-079：会话列表按最近内容更新排序

> 状态：Accepted
> 日期：2026-10-11
> 负责人：Mirage 维护者
> 工作项：M6-37

维护者要求左侧会话列表最近更新者在最上方。原生 ChatModel 保留稳定存储与选择 ID，
只生成最多 24 项的排序视图，不移动底层会话，避免事件处理中的指针或选择失效。
发送消息、新的规范回复/失败、流式内容和工具过程更新推进活动时间；切换会话、草稿
输入、旧事件、重复规范响应及历史查询不推进活动时间。相同毫秒的实时更新按本地
递增活动顺序排序；历史相同时间按稳定远端 ID 打破平局，不依赖发现响应到达顺序。

恢复使用既有 DialogHistory.recorded_at_ms；该字段是轮次规范记录时间，初次接纳
时写入，终态结算时更新后随现有历史持久化。旧历史仍可使用其原有时间，无新配置、
无协议字段、无第三方改动和新异步路径。只读历史不会使用查询时刻冒充内容更新。
流式/工具过程在进程内推进活动时间，最终结算保存历史时间；pending 原本不持久化。
空草稿继续不进入历史列表，置顶不自动选择会话或改变阅读位置。

验收覆盖旧会话上移、正在查看另一会话的选择/草稿保留、同毫秒顺序、历史乱序恢复、
重复查询与迟到事件、流式及工具过程、删除/清空；Native 模型/IPC/Runtime 回归与打包。
