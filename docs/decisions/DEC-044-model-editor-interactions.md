# DEC-044：模型编辑器的事务与交互恢复

> 状态：Accepted
> 日期：2026-10-06
> 依据：维护者要求实际运行应用检查模型页；M6-23；DEC-042/043

真实Release窗口发现：删除其他模型丢失选中模型参数，取消跳至活动服务，新增模型重启禁用服务，空白重复ID可保存，菜单外部点击不收起、Escape跳出内联编辑器，以及服务删除缺少确认。

ACK目录是持久状态，当前服务是独立编辑副本。刷新始终接纳目录，但不得覆盖未保存副本；取消按服务和模型稳定ID恢复当前选择，离线也可放弃本地修改。初次目录加载前禁止编辑，保存期间不接纳其他编辑操作。新增模型继承服务开关，删除按稳定ID并先保留当前参数，重复事件不能删除相邻条目。

切换服务、预设、新增服务、返回对话或外观时，未保存修改须提供“继续编辑”和“放弃并继续”。服务删除单独确认目标名称，取消不得写入Service。菜单外部点击/Escape收起；内联新增模型有取消入口，未确认ID不能被保存静默遗漏。服务名、模型ID、粘贴Key处理首尾空白，空名和重复ID提供可修正错误；Key内部非法字符不接纳，不记录密钥。

实现限于原生UI主线程状态与既有RuntimeBridge请求，不新建并发、持久化、凭据或依赖机制。实际窗口使用私有Xvfb、DBus、钥匙环和合成配置；验证Service ACK和像素，不发起推理、不改用户配置。状态回归覆盖加载/保存门禁、失败保留、取消/确认、重复事件、容量与参数保留，明暗最小窗口检查。Windows与辅助技术由维护者在目标平台补跑。
