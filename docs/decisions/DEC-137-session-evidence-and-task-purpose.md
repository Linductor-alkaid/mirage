# DEC-137：过程投影持续更新、同代子树展开与桌面任务用途声明

> 状态：Accepted（维护者要求解决最新会话暴露的问题）
> 日期：2026-10-29；负责人：Mirage 维护者
> 关联：M9-29/30/33、DEC-049/093/118/133/135/136

## 决策与承载

针对最新会话计时器继续增长、parts 停在早期的现象，已复现展示投影在动作验证
回填后越过40KiB工具分类预算、被 Runtime 拒收的缺陷。保留原 96 行、40/16/8KiB 分类预算，
不放宽 valid_parts。conversation 提供纯同步的预算收敛函数；最旧工具详情先压缩，
保留行身份、真实执行状态和有界摘要，优先保留最新结果。摘要明确标为展示省略，
不能作为执行引用或验证凭据。所有发布、验证回填、终态边界均收敛；终态回答包括
成功回答也入展示投影。非法身份/状态不予修复，剩余投影仍须通过严格 JSON/UTF-8 校验。

AT-SPI 的每次快照替换引用注册表仍是安全契约。增加一次展开 1–4 个同代子树的
有界能力，批量请求必须携带产生这些引用的 backend_scope。先验证窗口/代际和
所有根，再在总节点预算内采集、重编号和调整父索引，一次成功发布新注册表。
失败不替换旧表；旧操作 scope 始终失效。单子树旧 API 兼容，不跨代复用 @eN，
不做猜测式重试或缓存旧对象。仅支持 scoped snapshot 的后端提供该能力。

具有桌面 Provider 的 Runtime 产品在读取图像/树或执行动作前，须通过现有 desktop.vision.content
声明 navigation（仅导航/交互）或 begin（内容观察范围）。应用/窗口发现和紧急
释放可先执行，普通聊天不受影响；嵌入 API 默认兼容，Runtime 产品显式开启。
零桌面 Provider 的纯对话环境不额外暴露用途工具。导航可升级内容，内容不能降为导航；内容默认自动低分辨率拼图，仍沿原供应器和
实际 Completed 证据评估，不增加采样、模型请求或第二个任务状态机。导航完成
明确披露不证明观看或理解，内容完成沿 DEC-133 的引用和评估门禁。声明是模型对
用户意图的解释，不宣称已独立验证语义一致性；播放器/声音/真实在线精度仍待验。

以上均复用现有有限调用、Mira 循环和外部 Executor owner，无新线程、队列、调度器
或依赖修改。完整交付构建统一使用已有 mirage-native-product（DEC-092），涵盖
launcher/service/tray/native/pet；运行中的进程不会因构建自动更新或重启。

## 验证与退出

回归覆盖预算满后的验证回填及后续工具、最新失败与终态保留；批量子树同代、
节点预算、窗口/代际拒绝及动作失效；用途漏声明、导航、升级/禁止降级、默认自动
供图与内容完成门禁。执行 Debug、ASAN、UBSAN、TSAN 相关测试及完整产品构建，
同步示例、设计、计划、兼容证据和变更记录。真实视频收益和用户意图准确性未因
可控测试通过而关闭。实际结果见后续兼容证据。
