# DEC-131：多对象注意与显式唤醒优先级

> 状态：Accepted（维护者继续推进M9授权，细化DEC-121/129）
> 日期：2026-10-28；负责人：Mirage维护者
> 工作项：M9-29/18；部分扩展DEC-129单对象限制

## 背景与决策

DEC-130只压缩表示；单个矩形/对象无法表达多个目标的重要性。本增量扩展既有
focus工具，第三种互斥参数为targets：1–4个{object_ref, priority}，priority为
wake或observe，至少一个wake。引用逐个经已完成模型请求供给认证，再由任务
FeedLease原子校验全部当前版本；重复目标、过量、旧引用或任一失败均保留旧策略。
旧矩形/单对象参数与行为保持兼容，未实现新接口的feed默认拒绝。

新objects模式保留全部原始事件和预览在该任务的有界view中，仅在wait判断是否
立即返回event时使用重要性。只有confirmed的位置/外观事件，与显式observe
目标的source_epoch/ID/incarnation完全相符，且不与任一wake目标区域相交，才
延后本次事件唤醒。其余事件保守唤醒，包括非目标、身份不全、未确认、内容/关系
变化、出现/消失、媒体关键帧和来源屏障。延后事件下次请求仍自动提交，不ACK、
不删除、不重排、不猜测语义没变。关键事件唤醒仍受下一供给字节预算约束。timeout不证明没有变化；现有有界等待仍生效。

所有目标同版本移动分别跟随；任一目标未知/缺失/过期/内容或实例变化，或源/
context/gap/失败，整组单向失效、恢复全局并明确返回attention_invalidated。
选择整组退役避免失效目标被剩余低优先级掩盖；不自动复活。不依赖新图像、模型、
调度器、队列或worker，复用原串行任务owner、快照与可取消等待。每消费者≤4目标，
无像素，保留绑定字符串和目标元数据≤4KiB；采样/识别、其他消费者与权限不改变。
注意投影只输出身份/版本/框/priority，不重复请求ID或语义标签；供给仍≤8KiB。

## 备选与影响

不采用位置/外观首尾相同即语义相同，或由本地猜测任务重要性的方案；公开事件
不支持这些结论。不按优先级重排日志，避免cursor确认跳过未呈现样本。不将非目标
一律静默处理；本阶段只延后明确observe身份，保留保守唤醒。CV-only会使版本未知
而整组失效，沿用DEC-129限制；持久空间关注仍用矩形。在线token/调用收益与
自动任务语义去噪未由本契约证明，M9-29整体继续In Progress。

## 验证

验证多目标移动、1–4容量/重复/全observe/原子替换、同ID不同实例/来源、未知和
关键屏障不延后、区域重叠优先唤醒、延后事件保留及下一请求供给、等待中新事件/
失效/取消/超时、双消费者隔离、真实工具认证/参数/8KiB；五配置回归、服务/原生
前端构建与格式/公开依赖边界后提交。未执行目标平台/在线任务单独记录补跑条件。
