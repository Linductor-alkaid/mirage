# DEC-115：任务连续感知、有限事件流与按需帧

> 负责人：Mirage 维护者
> 工作项：M9-21；延续 M9-05/06/07/11/18/19/20、M7-35

## 问题及依据

最新本地聊天客户端输入任务的留存记录：100 次模型请求、99 次采集、15 次 OCR
阶段调用；36 次显式 capture、13 次 OCR 工具、20 次 exec，无 fill/type_text 调用。
可见失败包括 arrival_target_changed、target_pixels_changed、临时文件写入范围拒绝、
进程超时终止及语义快照失败。部分过程正文因展示预算已省略，不能从留存推断全部
失败原因、当时的完整工具 schema 或实际加载二进制。不得重放真实联系人发送任务。

现有背景采集、Mirador 连续协调器/事件和无帧查询已分别交付；生产消费者仍是按需
OCR，尚未在模型思考期间持续采样。瞬时变化不能靠模型循环主动截图补齐。

## 决策

1. 在任务已经建立的桌面共享会话上接连续感知，不新增授权会话。采集/输入严格串行；
   完整前台工具步骤暂停后台采集并取消其在途分析，避免后台取图改变 pointer/source
   水位或抢占显式 OCR。暂停是资源调度，不改变桌面权限。后台忙则有界跳过并计数。
2. 复用 ContinuousCaptureHost 的 Executor blocking worker、timer、latest mailbox 和
   背压；复用 VisualSessionHost 同一个分析 worker，使用隔离的后台 image session/
   coordinator，避免 ROI/IME 分析重置事件源。后台请求不取消前台请求，显式请求可
   取代后台工作；所有拒绝、取消、异常与关闭仍进入原有任务设施。
3. 通用视觉变化、OCR、稳定 ID、生命周期/注意规划使用 pinned Mirador 公开能力。
   Mirage 只映射事件、保留历史、附任务身份并决定通知优先级。出现/消失/文本改变/
   位置或外观改变/源重置携带源代际、实体实例、帧和时间；无覆盖/遮挡不宣称消失。
   未经确认的一帧提示可作为 observed/unconfirmed 通知及证据，不能冒充确认生命周期。
4. 选择有界内存游标流，避免写无界文件或轮询磁盘。事件数上限 256、逻辑字节
   256 KiB，未读最长 120 秒；模型成功响应后确认已供给游标，已读记录 60 秒后
   清理。读取不在正文中重放整段历史；过期/容量淘汰公开 dropped/gap 和水位。
5. 自动在下一次 Mira 请求附最多 16 条增量事件和至多 8 个实体/1 KiB 已读摘要，
   总体不超过 8 KiB，带年龄/gap。供给仅进当轮请求，摘要维持跨轮关联；不新增
   高频 VLM 循环。重复无变化由 Mirador 协调器抑制；焦点内变化优先，外围纯移动/低价值更新
   不挤占通知，但源/权限/接管屏障不受静音。可按最后目标 ROI 与显式注意条件调整。
6. 只为有价值事件保留缩小预览，最多 8 张、总像素字节 8 MiB、最长 120 秒；
   已读且未取图的帧也在 60 秒后回收，已取图帧在消费后退休。历史帧按 ID 按需
   获取，明确历史与尺寸限制，不能产生输入授权。缓存不能被陈旧订阅/句柄无限钉住。
   原始帧沿采集宿主最多两代，分析后释放；不为每帧生成 PNG 或送模型。
7. 背景默认 250 ms 采样，静态只做轻量变化门控；改变后的有界复查允许完成确认窗。
   OCR/推理忙时可能跳帧，必须可观察，不能承诺捕获任意短提示或固定端到端延迟。
   模型只在事件不足/目标需要时请求视觉细节。已供给的同一图片不自动反复发送。
8. 后台默认只跑 OCR 与轻量变化筛查；非文本区域变化以 visual_region_changed
   通知，不冒充识别出的对象。真实 YOLO 全帧约束/耗时会挤占短提示观察窗口，因此
   图标语义检测保持显式按需路线；后台 detector 为可选配置、默认关闭。其阈值必须
   沿用模型配置，不能把零阈值导致的候选预算失败当依赖缺口或放宽预算绕过。
9. 文本任务优先当前已暴露的 fill/type_text 工具。默认不以 exec、临时脚本或剪贴板
   绕行代替键盘方案；工具可用性与原因进入捕获回执，便于区分未注册和模型未选用。
   权限拒绝与视觉陈旧分别诊断，修正无价值的复观/重试；不取消接管、释放与系统
   授权边界，不以降低安全阈值伪造更高成功率。

## 实施与验收

接口先冻结，按隔离后台分析 → 会话采集串行包装 → 有限事件/帧缓存 → 自动供给与
确认 → 文本路由/失败归因接线推进。计划/真实平台逐项留证，未执行部分保持开放。
必测瞬时出现后消失、持续移动、焦点噪声、漏帧/gap、已读 60 秒、容量平台期、
只按需取帧、前台优先、无额外 PNG/VLM、撤权/取消/异常/准入拒绝及 shutdown。
受控脚本与私有应用测量模型步数、显式工具/图片数、事件延迟和漏检、峰值内存及
任务完成率；真实 Portal、Windows 与在线业务发送保持单独门禁。
