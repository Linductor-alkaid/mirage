# DEC-040：固定中文界面字体与会话行内基线

> 状态：Accepted
> 日期：2026-10-05
> 依据：维护者要求替换大小/高低不一致的字体；M6-12；DEC-033 / DEC-039

## 决策

界面中文和拉丁文字统一使用 Noto Sans SC Regular 2.004 官方简体中文区域 OTF，按上游
精确提交取源并记录摘要、OFL-1.1许可。字体作为静态资源，压缩归档进入Git，CMake离线
解包到目标assets，Linux/Windows安装资源同步。不使用系统TTC默认首个日文字面，
不把EUI示例装饰字体作为产品回退，不新增运行库或在线下载依赖。

维持设计中的EM字号与正文行高/布局/主题。pinned EUI将字号按ascender-descender
归一化，Noto SC 2.004的1448/1000度量会缩小字形；统一通过UI层ui_font_size换算
设计字号到EUI请求字号，并用于绘制、测量、换行、输入和选区。Markdown标题由EUI
按请求字号加6计算行高，输入按请求字号乘1.2计算行高，composer测量使用相同规则。
代码/图标维持各自字体和度量，不套中文系数。Markdown普通文字段使用共同的行框顶部和固定内边距，
避免逐字按字形轮廓居中造成上下跳动；按钮与图标继续按整个标签居中。
调整只位于原生UI公开DSL Adapter，记录EUI-20261005-006；不修改第三方代码。
该字体与本机ZCode系统中文回退Noto Sans CJK SC同系列、同简体中文字形；ZCode自身
采用系统字体栈，并没有唯一内置字体。不宣称英文系统字面或抗锯齿与Chromium像素相同。
代码字体保留现有monospace，字形覆盖之外的回退仍由EUI管理，字重仍遵循pinned EUI语义。

## 验收与限制

正常/最小、明暗、中英数字标点混排、Markdown粗体/代码/链接及输入框通过原生渲染
截图和既有交互回归；离线构建、打包字体/许可摘要一致。Windows与真实IME继续由维护者
在目标平台补跑，当前不宣称跨平台渲染验收。不改变Mira、Runtime或任何任务生命周期。
