# DEC-078：记住原生桌面授权

> 状态：Accepted
> 日期：2026-10-11
> 负责人：Mirage 维护者
> 工作项：M7-10 第六增量，承接 DEC-077

## 背景

维护者要求设置中一次授权，后续任务及产品重启恢复，减少反复选择显示器与控制开关。
Portal RemoteDesktop v2 支持 persist_mode=2 与单次使用的 restore_token。本机接口为 v2。

## 决策

按维护者 2026-10-11 对入口位置的澄清，会话输入框内「默认权限 / 只读模式」菜单直接
提供「授权并记住」「忘记授权」与真实状态刷新；桌面工具设置页显示同一状态并复用相同
请求处理。菜单打开仅刷新状态，系统共享只由显式授权操作触发。两种会话访问模式与
系统授权分别判定，授权不会修改本轮访问模式。入口修正由 M6-38 跟踪。持久配置
只保存 remember_desktop_authorization 布尔偏好；恢复令牌保存在系统钥匙环专用项，不进
IPC、模型、普通配置、历史或日志。所有请求和钥匙环调用由 Runtime 唯一 Executor 管理。
授权等待单独提交可取消有限任务，保留 future、限制一个管理请求，不阻塞控制面。

组合读屏/输入的恢复只通过 RemoteDesktop.SelectDevices 设置 persist_mode=2 和
restore_token，不在 ScreenCast.SelectSources 设置持久选项。使用前删除旧单次令牌，
Start 后有合法设备/尺寸及新令牌才确认记住；原子替换失败明确报错。进程退出与任务结束
关闭共享会话，下一个任务创建新会话恢复系统授权，不持久保存流、旧图或执行引用。
记住控制授权后只读任务可恢复同一授权，但不获得输入方法；动作仍走原权限与 scope/epoch
门禁。取消、takeover、失败释放和关闭顺序沿 DEC-077。

忘记授权先关闭复用偏好并推进授权代数，运行中平台操作协作取消并释放输入，旧会话后续
操作拒绝；删除本机恢复令牌。正在等待模型的任务在下个推进或结束时关闭流，不宣称系统
已即时注销所有 Portal 权限。用户仍可通过系统停止共享或撤销权限，系统可以因锁屏、源
变化、撤销或恢复失败再次询问。UI 不承诺永久授权；「已记住」只证明本机有恢复令牌，
不等于持续录屏或授权永不失效。

## 备选及范围

不保持进程全局永久录屏/输入会话，避免资源持续占用、跨任务坐标与引用混用；不旁路
系统授权。授权只需 Start 成功，不以首帧到达作为授权成功条件，静态画面交帧仍按
DEC-077 开放。无新增依赖能力缺口或 pin 变更。

## 验收

自动覆盖保存偏好、旧配置合并/损坏拒绝、IPC 编解码、令牌轮换/读取写入失败、缺失
令牌/权限、授权忙/取消/撤销竞态、只读输入不可用和 shutdown。GNOME 单次系统授权
后，两个独立任务及新进程恢复不得重复弹窗；需维护者实际共享，未验不标完成。

依据：[RemoteDesktop](https://flatpak.github.io/xdg-desktop-portal/docs/doc-org.freedesktop.portal.RemoteDesktop.html#session-persistence)。

管理、任务隔离和恢复条件继续适用，系统授权不覆盖会话模式限制。
