# DEC-120：有界事件帧时间拼图

> 状态：Accepted（维护者要求尝试多帧降采样拼图，2026-10-27）
> 日期：2026-10-27
> 负责人：Mirage 维护者
> 工作项：M9-24；关联 M9-23、[DEC-118](DEC-118-significance-gated-perception-and-scoped-snapshots.md)

## 背景与问题

最新持久化会话的视频任务只证明打开页面、播放画面与读取页面文字，不能证明消费
完整内容。DEC-118 的事件抑制和提示修正已存在，但单张 event_frame 缺少便宜的
时间对照入口。研究与现状核对见
[调研记录](../research/2026-10-27-layered-perception-and-video-storyboards.md)。

## 决策

1. 在 Mira Adapter 增加 `desktop.vision.storyboard`，显式接收 2–4 个现有
   `frame_id`，只读取任务 feed 已保留的弱引用，不发起 capture、OCR、detector 或
   独立模型请求。此阶段是稀疏历史证据打包实验，不新增视频下载或解码器。
2. 按真实观察时间排序，2 列、最多 2 行，每格最长边 320px、保留纵横比且不放大，
   复用 Mirador `resize_area`。合成图最多 640×640 BGRA（1.5625 MiB），继续走
   既有 8 MiB 图片工件和请求预算。JSON 给出每格位置、原始预览尺寸、帧序号、
   source_epoch、相对时间、年龄和相邻时间差；不是播放器时间或连续覆盖证明。
3. 仅接受当前 source_epoch 的有效事件帧；重复 ID、不同尺寸、相同观察时刻、
   无事件关联、未知/已消费/过期预览明确拒绝或报告 unavailable，不补抓、不复制
   同一帧充数。保留 dropped/filtered/resync，始终声明 sparse、audio=false、
   complete_video=false。历史拼图不签发输入引用，不作为当前状态验证。
4. 只有模型请求实际消费拼图后才逐帧 ACK；工具返回和仅供给文本不算消费。
   未变拼图不重复送模。沿用任务 owner、取消、权限和现有同步工具执行路径，
   不创建线程、队列、计时器或新生命周期。
5. 视频任务提示要求报告实际观察区间与局限，标题/简介、播放状态、时间经过均
   不能替代内容理解。拼图适合概览；文字/细动作需原帧或 ROI，音频结论需音频/
   字幕证据。不能承诺 token 固定下降四倍或已解决视频任务完成率。

## 备选方案

- 单帧逐张读取：保留用于细节，时间概览优先一次打包。
- 模型内 token 合并/视频编码器：需要匹配模型，不在任意图像 API 前模拟 embedding。
- 每固定时间强制调用 LLM：违背低负载目标；本次工具只在任务需要时使用。

## 影响与风险

稀疏事件帧可能遗漏缓慢动作、字幕变化或全屏视频。拼图不能解决生产者事件选择、
OCR 分频和每帧 tracking；这些仍由 M9-23 及 MIRADOR-20261027-001 跟踪。
像素媒体启发式不等于语义分类器。新工具公开面由工具契约测试覆盖，生产默认
采样周期不变。

## 验证方式

合成彩色帧验证排序、保纵横比、像素排布、容量、过期/缺失/源切换、取消、消费
ACK、零额外 capture/识别和单次供图；Debug、ASAN、UBSAN 专项。真实媒体模型
任务与资源/token A/B 保留 M9-12/M9-24，由 Mirage 维护者在固定模型和可复位桌面
就绪后执行。未执行前不宣称端到端改善。
