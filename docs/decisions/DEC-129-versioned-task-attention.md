# DEC-129：按对象版本绑定任务注意区域

> 状态：Accepted（维护者授权继续M9，按DEC-121实施M9-29首增量）
> 日期：2026-10-28
> 负责人：Mirage维护者
> 工作项：M9-29，关联M9-13/18

现有focus只有坐标，不能表达“关注刚才识别出的同一对象”，也不能在来源重置后
自动撤销旧过滤。本增量扩展desktop.vision.focus：或者传原四项矩形，或者只传
object_ref。引用只能来自本任务已完成模型请求实际供给的semantic_scene；绑定
source/context、对象ID/incarnation/content_revision与原证据帧，不以模型自报ID授权。
同一版本的已确认对象移动时更新区域；内容/实例/来源/上下文变化、对象缺失、
未知/过期证据、观察gap或来源失败使对象绑定单向失效，恢复全局事件观察，明确报告
attention_invalidated。旧引用不会自动复活；需要新引用或显式矩形/清除来重设。
坐标模式按来源epoch与已有场景context绑定；来源变更/gap/失败后也恢复全局。

策略由原FeedLease串行任务上下文持有，每消费者最多一项、无像素、无后台任务，
不修改共享采样/识别策略、权限或其他消费者。沿用已有kairo快照/Topic；等待期间
通过现有可取消wait的有界检查重验策略，不增加线程、队列、定时器或LLM轮询。
出现/消失/来源屏障及未确认区域观察继续绕过区域过滤。对象注意只表示任务意图，
不是当前内容覆盖、语义标签、动作引用或任务完成证据。

PerceptionView和下一轮自动供给携带注意模式、active、失效原因、目标版本及区域；
wait对注意失效明确返回attention_invalidated。原始事件、cursor/ACK、帧保留与
8KiB供给预算不变。工具严格拒绝混合形式、溢出、缺项和非法范围，失败不改旧策略。
未实现对象注意的Feed默认拒绝，保留已有坐标模式兼容。

本阶段不交付多目标重要性、事件窗口合并、跨未知帧精确语义继承或自动内容任务状态机；
M9-29仍In Progress。当前layered CV-only周期不证明对象版本有效，保守失效可能较频繁，
持续观察固定空间应使用显式矩形，不用近似tracking冒充内容证明。性能与跨平台结论
不沿用DEC-128作新增保证。

验收：未供给/未完成/外任务/旧引用拒绝，同版本移动、内容/实例/来源/缺失/过期/gap
失效、失效后全局事件恢复、关键事件保留、双消费者隔离、等待中失效/取消/超时、
真实工具供给及8KiB上限；Debug与sanitizer专项、native构建、格式/公开边界后提交。

能力核对：Mirador公开fusion/snapshot的stable_id只在源session内有效，不承载
模型请求认证或消费者任务意图。本增量复用Mirage既有VisualScene版本与已完成
请求供给表，在产品FeedLease维护任务策略；不实现新的视觉关联/跟踪算法。
