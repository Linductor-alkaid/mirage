# DEC-046：会话思考选择与空会话恢复

> 状态：Accepted
> 日期：2026-10-06
> 依据：维护者本轮要求；M6-26；DEC-038/039/043

思考选项位于会话输入栏，按模型及方言提供可执行的选项。模型设置不再要求用户先启用
思考能力，也不展示“此协议的扩展思考尚未接入”。MiniMax-M3 提供默认、关闭、开启；
M3.1 Flash Preview 提供默认及官方支持的深度，不能关闭思考。其他 Messages 模型使用
明确的模型能力映射；未知模型不猜测能力。OpenAI 兼容方言沿用 reasoning_effort。
选项必须经请求、Gateway、ConversationLoop 到达 Provider，不能仅改变按钮文字。

Mira 的 Messages 缺口按 MIRA-20261006-002 登记，补齐有界自适应思考块及签名的解析、规范
序列化、工具回填，依赖提交须有独立 PR。思考内容不作为正文或工具指令执行。

空的历史会话不恢复、不持久化。Runtime 主会话仍属本次运行设备；有 journal 或已结算
对话的历史会话保留稳定 ID。恢复须预留主会话名额，容量拒绝保留草稿并给出恢复操作。
不通过删除非空历史或无限提高容量掩盖生命周期错误。

默认 max_sessions=25，与原生 24 条可见会话预算对齐并预留 1 主会话；配置覆盖仍严格生效。
保存的非空历史已达到容量时拒绝启动并保留源文件，不能部分恢复后覆盖丢失其余记录。
本决策替代 DEC-043 中“首阶段 thinking 拒绝”的局部边界，其他协议/凭据/视觉决策继续生效。
