# DEC-048：统一原生控件文字内边距

> 状态：Accepted；日期：2026-10-07；关联：M6-30。

维护者要求修复思考按钮右侧留白不足，并统一各模块控件文字边距以防复发。
当前EUI ButtonBuilder默认按左右16px计算图文按钮文字宽度；纯文本按钮未留文字内边距。
缩至84px的思考按钮无法容纳四字13px标签，造成绘制越出文字布局区域。

Mirage在UI边界复用EUI按钮的事件、状态与视觉设施，通过共享Adapter统一按钮/输入框
8px文字内边距、4px图文间隔，并在实际字体测量的可用区域内省略长标签。
完整控件组（图标、间隔、文字）两侧保持相同8px；纯文本居中显示于同一安全区域。
图标按钮保持现有中心对齐。布局分组、正文及面板缩进按已有层级，不作全局压缩。

模型与思考宽度使用同一尺寸函数，思考选项按最长标签留足宽度；右侧工具组位置从
相邻控件尺寸与统一间隔推导，避免依赖重复的固定坐标与手写扣减。
所有产品按钮经同一入口创建，渲染测试验证实际文字测量不超过文字框、图文组
两侧内边距一致、输入使用同一token。依赖升级使布局契约漂移时，回归会失败。

这是Mirage产品样式适配，EUI公开Theme metrics及DSL元素支持承载，无需修改依赖或登记能力缺口。
无新并发、公开API、IPC或持久化变化。

M6-31补充：封装默认清空上游示例文字“Button”，无文字的图标控件不会生成隐藏文字框，
避免新增图标控件破坏同一内边距规则；原生遍历式边距回归覆盖。
