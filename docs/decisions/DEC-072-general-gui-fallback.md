# DEC-072：通用 GUI 回退与截图区域点击

> 状态：Accepted
> 日期：2026-10-11
> 负责人：Mirage 维护者
> 冻结里程碑：M7
> 工作项：M7-15
> 替代/被替代：无（扩展 DEC-055/058/062/071）
> 依据：维护者授权执行快捷工具不可达时的视觉和键鼠通用路径

## 背景与问题

会话偏向应用/URI 快捷工具，缺失时没有等价 GUI 路线。编号点击依赖检测结果和前台
窗口边界，纯图标、桌面启动器和菜单不能覆盖。需要把截图中可见区域转为受控输入。

## 决策

增加 desktop.vision.click_region，不依赖 OCR/SoM。参数为最新 screen.capture 的
image_scope、environment_epoch、target_context（window/display）及图片像素
x/y/width/height；窗口上下文匹配 window_id，显示上下文匹配 display_id。
显示上下文允许前台窗口之外的桌面/面板/菜单；capture_scope 不允许扩大范围。
图片必须已进入当前模型请求。每次捕获颁发唯一 scope，即使像素相同也不复用身份。

最多保留一份 32 MiB 源像素、显示几何、截图时前台状态与比例；用 Mirador 公开变换
映射源区域并点击中心。授权及既有 ActionCoordinator lease 后检查前台/源窗口/显示
几何，重新捕获该区域逐行比较像素，最终检查取消/epoch。只核对所选区域，允许无关动画；
像素一致不保证业务语义。区域/重验各限 8 MiB，沿用每轮四次采集、完整左键最多一秒。

请求供图仍保持五秒新鲜度；已供图的区域意图最多保留六十秒，仅在执行前新截图匹配
后可用。旧图不是当前事实，编号/语义引用不续期；换图/接管/取消使意图失效。目标移动
或区域改变时无副作用拒绝，必须重新观察，不能宣称实现了移动目标追踪。

新增局部条件 foreground_changed、foreground_title_equals、display_text_exists：
分别固定动作前前台状态并证明变化、检查新前台准确标题、对固定显示范围取得新 OCR
证明唯一高置信度精确文字。显示上下文可无初始前台窗口。局部条件只验证推进步骤，
后续必须新观察和独立页面验证，不能冒充业务成功。

规划优先能完成当前步骤的已暴露快捷能力；快捷工具不覆盖下一步、未暴露或明确无副作用
拒绝时，考虑语义、视觉、鼠标和键盘等价路线；已派发
或不确定先验证，不自动重复。不激活无关窗口；所有可用路线不可达才报告能力缺失。
复用 Mira canonical 工具/循环/WorkflowRuntime、Mirador 变换和既有 OCR。适配属于
Mirage 职责，不修改依赖，不新增并发设施；后续本地语义/OCR/模板重新定位沿用 M7-11。

## 备选方案

只修改提示不能点击无编号图标；无来源坐标缺少图像身份和执行前核对；全屏像素比较
易受无关动画影响。选择有来源区域及局部重验，不把局部像素核对当作语义重新定位。

## 影响与风险

权限资源区分窗口和显示器，保留焦点/几何检查。检查与派发不是 OS 原子事务。
Linux X11 先验收；其他平台独立补证。离线脚本不证明在线模型能自主选择正确区域。

## 验证方式

无 Application/Accessibility Provider 的私有场景验证截图打开目标窗口，再用
Ctrl+L/文本/Enter、新观察闭环。另验真实 Xvfb 捕获与输入。覆盖负原点、比例、
窗口外目标、范围限制、重复图 scope、像素/前台/显示变化、权限、取消、超时、异常、
不确定封锁和只读装配；运行全量及相关 sanitizer。

## 2026-10-12：在线会话选路澄清

维护者授权结合本机 Mirage 会话更新工具提示。相关轮次已有可交互截图和
`desktop.session.click`，模型仍因缺 `desktop.window.list` 判断不能让可见浏览器取焦；
用户提醒后才点击。另有 `open_uri` 仅证明应用运行、OCR 刷新废弃旧 `image_scope`、
点击后的新帧只证明局部进展等回执。会话内容不复制进仓库。
原 `native_ocr` 宿主说明还在浏览器被 Mirage 遮挡时直接建议用户移动窗口，未先检查
本轮是否已经开放可执行的图像绑定点击；这与完全访问模式的工具能力相冲突。

宿主将鼠标、按键、文本和滚动表达为完全访问模式中的常规桌面执行路线，用户无须点名
工具。每一步按本轮真实工具集与目标选择：快捷或语义工具能完成该步就使用，否则观察
可见界面并使用有来源引用的输入；没有窗口 API 时，可点击目标窗口明确可见的非交互
区域取焦。仍须先取得可执行观察、动作后重新观察并验证；OCR/截图换代必须使用新引用。
只读模式不宣称键鼠可用，系统权限、取消、不确定副作用和业务终态门禁保持原契约。
在线模型无需用户提醒的自主选路与原浏览器任务仍需实机验收。
