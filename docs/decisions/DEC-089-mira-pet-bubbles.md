# DEC-089：mira_pet 思考滚动行与输出短句气泡

> 状态：Accepted
> 日期：2026-10-14
> 负责人：Mirage 维护者
> 冻结里程碑：M8-11（M8-06 前）
> 替代/被替代：扩展 DEC-084 的角色呈现，不替代进程/播放/安全契约

## 背景与问题

桌宠已能播放动画，维护者要求在 M8-06 开始前增加头顶气泡：思考用一行、角色窗口宽的
实时渲染行，模型回答用一句高度简短的核心概括。维护者进一步确认思考泡只为体现
正在进行，采用连续横向滚动，无需让用户读完思考过程。

## 决策

1. 在 M8-06 前插入稳定编号 M8-11，不挤占或重编号已有任务。思考泡采用圆润横泡和
   两个小圆尾，对话泡采用圆角框与短尾尖，均一行、宽度等于角色画布，优先放在头顶。
   当前 240px 角色画布保留，不恢复底部状态条。明暗色与字体沿用原生设计系统。
2. 思考文字默认从右向左连续滚动，新内容追加不逐 token 重置；对话泡静止显示一句核心
   大意，保留否定、未验证与不确定限定。气泡更新独立于动画首轮切换。
3. Runtime/Integration 投影当前模型请求，桌宠不直连模型。回答复用既有正文预览与
   规范响应，暂定有界抽取式压缩、不增加摘要模型调用；效果不足时保留未完成门禁。
   思考公开流缺口登记为 MIRA-20261014-004；缺席时滚动“正在思考…”状态提示，不能
   把终态 ThinkingPart 伪装成实时流。提示交付不代表真实思考文字门禁通过。
4. 只呈现当前 owner/source/request，重试和身份改变清空，迟到/乱序不恢复气泡。
   输出终态暂定保持 5 秒；工具阶段与安全状态清除，隐藏期间收到文字不得恢复窗口。
5. 通信与滚动唤醒复用既有 Executor/Topic/LatestMailbox/timer，保持预算、取消、失败
   与 shutdown 可见。IPC 在实施中以可探测的加法扩展与 golden 同步冻结。
6. 气泡点击穿透、不抢焦；角色仍可拖动。M8-06 处理角色、泡身、尾部和阴影的全部视觉
   占位，几何变化重新确认并观察，截图/OCR 与动作目标统一验收。

尺寸、滚速、更新间隔及保持时间已用于 Linux 原生实现，wire 为可探测的可选扩展，
授权消费 Mira PR#94 merge 22d9577。合成渲染与 fixture 通过不能替代真实桌面/在线供应商验收。
实现与限定证据见 [M8-11 记录](../compatibility/mira-pet-bubbles-runtime-20261014.md)。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 思考显示最新短句、不滚动 | 维护者明确选择连续横向滚动，未采用 |
| 输出逐字滚动或完整回复 | 超出一句核心大意的范围，桌面上信息负担过大 |
| 桌宠自行请求摘要模型/解析 SSE | 破坏 Runtime/依赖边界，未采用 |
| 气泡等待动画首轮结束 | 可能延迟 8.9 秒，无法体现当前模型工作 |

## 影响与风险

窗口扩展影响保存位置、输入 Shape 和桌面占位；气泡输入穿透不能替代视觉避让。
抽取式概括需要语义语料验收，截断不足以满足核心大意；思考真实文字需要上游公开能力，
不得以状态提示关闭该门禁。浏览器设计演示不能证明原生窗口性能或跨平台效果。

## 验证方式

按设计第 8 节覆盖滚动、概括、来源代数、安全清除、窗口、避让及 Executor 故障矩阵。
浏览器演示只验证视觉方向；产品验收与 M8-06/07/10 独立取证。
