# DEC-036：上下文占用比例与真实数据来源

> 状态：Accepted
> 日期：2026-10-04
> 负责人：Mirage 维护者
> 工作项：M6-06

## 背景与决策

维护者指定按ZCode的比例圆环展示上下文。沿用DEC-035外观，采用小圆环入口、紧凑
Token摘要和横向进度条；点击展开，保留键盘操作。以pinned Mira ModelResponse.usage
最近一次成功请求的input_tokens为分子，只接受Exact/ProviderReported，不把字节、输出
Token或多次调用的累计消耗作为上下文占用。工具循环取最终回复调用的输入用量。

新增可选model.context_window_tokens配置（0/缺失表示未知，非零2048–2000000）。
它是用户配置的上下文窗口预算，同时映射Mira公开ProfileLimits，不宣称供应商自动发现。
无配置时保持既有Mira默认运行预算，但UI分母未知。用量随轮次通过可选context_usage
对象传输，包括input_tokens、window_tokens和model；旧消息缺字段仍可解析，旧JSON保持。
UI显示“上次请求”，草稿与尚未完成的请求不伪装为实时Token计数；失败/取消不产生新占用。
历史持久化暂不保存用量，服务重启后的旧轮次显示未知；不得从文字重建伪精确值。

## 替代方案与影响

拒绝字节比例和硬编码供应商窗口。没有供应商用量或未配置窗口时显示空圆环与未知说明。
不新增异步任务、不变更Executor所有权，不修改pinned依赖；数据沿现有结算/事件/历史路径。

## 验收

检查已知/未知/溢出、最新轮次与迟到事件、模型预算校验、可选IPC兼容及真实模型请求。
Linux正常/最小窗口、明暗主题截图；Windows待维护者在目标环境补跑。
