# DEC-047：原生会话与设置控件密度

> 状态：Accepted；日期：2026-10-07；关联：M6-29。

维护者要求对照[ZCode官网](https://zcode.z.ai/cn)的应用设计缩小偏大的控件。
沿用DEC-041阅读字号及明暗色阶；按ZCode固定源码29628c9公开组件尺寸收紧操作控件。

- 会话输入栏工具28px，发送/添加图标14px，上下文圆环16px；正文和输入保留14px。
- 普通下拉菜单宽280px、行高32px、间隔4px；引用与用量详情仍320px，保持内容可读。
- 设置页主标题20px、服务标题16px；外观描述/主题选项14px，主题按钮88×28px。
- 模型输入框保留32px；添加模型/保存/取消按钮28px，详情内缩进24px不变。

通过缩减控件和分组空隙而非全局缩放实现密度，保留原生字体EM修正、服务ACK、
取消和草稿保护、删除确认、可调侧栏及窗口控件尺寸。无需改动依赖或并发设施。
