# DEC-107：共享观察节奏与取帧呈现边界

> 状态：Accepted
> 日期：2026-10-18
> 负责人：Mirage 维护者
> 工作项：M7-10 / M7-14 / M7-19 / M8-06
> 细化：DEC-074 / DEC-081 / DEC-103 / DEC-105 / DEC-106

维护者要求长任务不因累计帧数停止，减少重复截图和 token，并使桌宠避让仅覆盖必要的采集区间。

1. 删除任务累计截图次数上限；保留单帧内存、单次时间、权限、任务取消、源帧水位与终态关闭。最新帧及 artifact 替换回收，长期观察不累积存储。
2. 桌宠租约在实际取帧时准入，取得自有像素后立即核验和恢复。系统授权、PNG 编码、OCR、模型推理不持有隐藏租约。桌宠暂停刷新但保留唯一一份有界解码动画和最后画面，恢复只重新上传，不清空后重解码。输入所需避让仅覆盖输入派发，不能包含后置 OCR。Portal 在授权和连接完成之后准入，源帧时间水位在准入之后读取。
3. 已发布、未过期且 epoch/授权/来源一致的画面可用于紧随其后的同源截图/OCR；不重新准入隐藏，不延长采集时间或引用寿命。五秒后，交互画面只作为已有目标意图的历史规划输入保留至 DEC-081 的 60 秒边界，不作为新鲜完成证据；输入仍重新取帧核验。动作后的验证始终要求更晚源帧。成功动作回执携带验证所得的最新 image_scope/epoch，下一步直接使用。
4. OCR 超时表示分析未完成，不表示画面失效；反馈不得诱导重新截图。已有画面可继续视觉判断。不得把帧到达或输入释放称为业务目标完成。
5. 使用 pinned mirador 的变化检测提供画面变化提示，帮助模型避免无进展的循环；变化提示不能替代动作守卫或新帧证明。

GNOME Portal 没有向应用提供“仅合成时排除一个窗口”的公开契约。撤下、合成新帧、恢复仍跨进程进行，不能承诺物理显示严格只缺一帧。此轮消除工具级长时间隐藏；单帧观感须真实 compositor 测量，不以夹具推定。其他 compositor 继续按 DEC-106 显式降级。

验证：最新重试脱敏记录、超过旧 4/8/32 帧上限的持续观察与输入、取消/撤权/失败/关闭、租约先于取帧且早于编码/OCR释放、缓存不越过 epoch/期限、动作回执可直接驱动下一步。真实 GNOME 观感及在线业务验收保持开放。
