# DEC-050：按实际渲染缩放测量普通文字

状态：Accepted。日期：2026-10-08。工作项：M6-32。

维护者截图中的“你会做什么”在宽页面上被错误拆成两行，末字落在气泡外。
原气泡采用逻辑字号的静态测量；实际渲染按物理字号排字。字体的像素量化不具有缩放不变性，
恰好容纳逻辑宽度的五字短句在2×渲染时不足一行，原高度仍为一行。

Mirage UI复用 pinned EUI 的公开 TextPrimitive 实际字形布局，不修改依赖。
窗口适配层以当前 framebuffer 宽度与本次 compose 逻辑宽度推导渲染比例，
字体EM修正、字号、换行宽度和行高均按同一比例测量，再换回逻辑尺寸。
用户气泡的自然宽度在物理像素上向上取整并加一个物理像素余量；在当前列宽和576px上限内
撑开，保留左右12px、上下8px内边距。只有超过可用宽度或含显式换行时才换行。
正文发出的 maxWidth 与高度测量一致；普通文字高度共用同一布局入口，避免各模块独立猜测。
选择覆盖层采用同一正文尺寸。

布局缓存由单一 UI 状态拥有，最多128条、256KiB源文本，按FIFO淘汰。
缓存键包含文字及实际字号、换行宽度、行高；缩放或列宽变化自然重新布局。
不新增线程、调度、公共平台类型或无限缓存。

不选择仅裁剪气泡内容（会丢失末字），也不固定扩大所有气泡（无法保证其他字号/缩放）。
验收必须用实际 TextPrimitive 对生成的正文元素独立排字，覆盖1×、1.25×、1.5×、2×，
1180/860px窗口、明暗主题、中英混排、长串、显式/末尾换行和emoji；五字短句必须单行，
所有字形必须在气泡内，选择与复制保留。目标平台真实显示器验证另行记录。
