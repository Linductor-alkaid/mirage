# M9 首增量：视觉对象状态与语义绑定

> 状态：In Progress
> 日期：2026-10-15
> 负责人：Mirage 维护者
> 依据：DEC-091；工作项 M9-01/05/13
> 范围：同步、单 owner、无像素的 Core 状态层；native/IPC 和连续帧调度尚未接入。

## 所有权与输入

`desktop::VisualScene` 属于当前视觉源会话的串行 owner，不创建任务、线程或队列。
像素、OCR/YOLO/闭合检测、身份匹配由既有 Platform/Mirador 集成提供；此层仅管理
产品对象状态和 LLM 语义，不重新实现视觉算法。调用方不得并发调用；跨上下文
输入与发布仍须经 Runtime 的 kairo 通信原语。

源会话固定于构造参数，context_revision 表示页面/场景换代且只能递增；同源的
frame_sequence 严格递增。首次/场景换代必须提交完整集合；普通增量需要匹配
base_revision。完整集合也按字段比较，只为变化对象生成新记录和 delta。
跳帧后的变化由上游相对已提交基线形成，不从相邻采集帧推断缺失变化。

对象键为 id + incarnation；content_revision 由可信感知 owner 维护，在文字、
类别、外观或相关语义依赖改变时递增。坐标移动不增加 content_revision；若字段
内容变化却未增加版本，拒绝整个提交。identity_confirmed 只表示本地身份已核对，
不是可点击权限；pending 表示尚未分析的区域，不能用作有效语义依据。

## 标定

绑定携带源会话、场景、对象/实例、content_revision、标定帧、模型 request_id 和
label。校验所有版本及当前身份后接纳；位置改变但内容版本相同可接纳晚到标定，
内容/实例/场景已变则拒绝。每对象首增量只保留一个最新语义标签，不支持自动
永久记忆；多字段依赖和 native 模型标定工具留给后继增量。

模型 request/image 来源鉴权必须先由可信 owner 完成；本层只校验源会话与对象
版本，`model_request_id` 字符串仅为归因，不是调用方自行提供的身份凭证。

无关更新和确认的移动保留绑定；身份未确认/pending 或内容变化使绑定 suspended；
身份恢复且原内容版本一致可恢复 active。实例替换/删除/场景换代撤销旧绑定。
LLM 推断不写入 OCR、detector 类别或平台 role，也不构成动作后证据。

## 容量与提交

暂定首增量默认：256 对象，512 KiB 逻辑存量，4096 字节/对象文本字段，1024
字节/label，128 字节/request_id 与源会话标识；最多 256 upsert/removed 每提交。
每记录按 `sizeof(VisualSceneRecord) + 4 * sizeof(void*)` 固定开销计费，字符串
按实际字节计费；变更暂存与输出各至多一个预算内场景，不复制未变字符串。
工作区还有每提交有界的 ID 集合与单记录临时值。这是有界逻辑预算，
不是进程 RSS 承诺。输出 delta 也受相同对象/字段上限约束，当前层不保留 delta
历史或像素。全链路帧/GPU/旧代快照预算仍待 M9-07 冻结与实际测量。

所有输入先验证并预算后提交；预算/重复 ID/版本/分配失败整次拒绝，旧基线与绑定
不变。增量只包含改变和删除的对象；完整快照仅在显式请求/重建时复制。输出是
调用方持有的值，不得在上游无限保留；本层没有绕过队列/历史容量的共享帧引用。

## 验收

单元验证完整/增量、无变化零输出、移动继承、内容失效、身份不确定/恢复、场景
换代、晚到标定、ID 复用、删后重建、非法输入/容量拒绝原子性及长序列存量平台期。
Mirador mapper 只映射已有对象数据，不凭融合 ID 自动宣布 identity_confirmed。
上述测试不证明模型接线、帧采集性能或端到端工具往返已改善。
