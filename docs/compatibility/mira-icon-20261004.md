## Dock 反馈后的补验

维护者指出 Dock 仍无图标；前节截图仅显示应用窗口，原 ship 不能作为 Dock 验收。
窗口已有 WM_CLASS 和 _NET_WM_ICON，但缺少对应 Linux desktop entry。新增
org.mirage.native.desktop 模板和显式 mirage-native-register-desktop 注册目标，
在当前用户 applications 目录注册 Release 构建，并重启原生预览。

已执行：Debug/Release 目标构建、两种构建的 desktop-file-validate、Gio.DesktopAppInfo
解析 app identity/Exec 可执行路径/Icon 文件路径、真实窗口 WM_CLASS 核对。均通过。
GNOME AT-SPI 树中存在 name=Mirage、role=push button、SHOWING=true 的 Dock 按钮，
证明 GNOME 已识别运行中的应用；[关联证据](../../.impeccable/review/native-dock-registration-evidence.json)。
图标本身仍为同一原图，未改 UI 代码、素材、并发或生命周期。

GNOME Screenshot/Introspect 方法拒绝读取；未绕过，也未获取 Dock 像素截图。
因此本轮确认应用身份和资源关联，不把它写成 Dock 像素视觉验收。
